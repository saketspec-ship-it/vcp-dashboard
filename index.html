Criterion 8 there is a crude proxy (beats Nifty 50's 3-month return), not a true percentile RS rating, and not the same thing as the RSI(14) column here. "Listing Price" is the earliest available monthly close from Yahoo Finance -- a proxy for the IPO price, not the exact day-1 figure. "Market Cap" is in ₹ Crore, from screener.in. Click a column heading's label to sort (click again to reverse). Click the ▾ button on any heading for an Excel-style filter: a searchable checklist of that column's values (tick only the ones you want); numeric columns also offer a "Number filter" box for conditions like >100 or a range 50-200. Filters on different columns combine (a row must pass all of them).
